# 同事安装说明

打开 DeepSeek Harness → 插件 → 添加插件右侧下拉箭头 → 安装第三方插件。

在「包名或地址」中粘贴：

```text
github:Raindmore/dsh-lulu-butler-theme#v1.0.0
```

安装完成后启用 `dsh-lulu-butler-theme`；没有立即变化时，重启一次客户端。

换装位置：左下角更多 → 设置 → 通用设置 → 噜噜 · 小管家。

外观选择浅色对应奶油日间，深色对应可可夜间，也可跟随系统。

如果 Git 来源不可用，也可在同一输入框使用预构建安装包直链：

```text
https://raw.githubusercontent.com/Raindmore/dsh-lulu-butler-theme/main/dsh-lulu-butler-theme-1.0.0.tgz
```

已验证 DSH 0.2.1-rc.2 的客户端插件接口。电脑需要可以访问所选安装来源。
